# Race Result comes from the Best Effort, not from Moving Time

Everywhere else, the dashboard uses Moving Time. A Race Result is the exception. It is the Strava Best Effort over the Goal Race's distance, taken from the longest Run on race day. Moving Time leaves out pauses that the official clock counts, and the elapsed time of the whole Run includes any extra distance the watch measured (42.58 km for a 42.195 km marathon). The Best Effort comes closest to the official finish time. If the Goal Race distance has no Strava Best Effort, the Run's elapsed time is used instead.
